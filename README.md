# crawl2md — 구현 시작점

```
crawl2md-구현명세.md   ← 이것만 읽고 전체 코드를 작성한다
sites/wikidocs.yaml    ← 검증 완료된 1호 어댑터
fixtures/              ← 네트워크 없이 테스트를 돌리기 위한 실데이터
```

## 순서

1. `crawl2md-구현명세.md`를 처음부터 끝까지 읽는다. §0에 읽는 순서가 있다.
2. §3 데이터 계약과 §5 모듈 API를 먼저 코드로 옮긴다 (models.py, adapter.py).
3. §12.2 테스트를 먼저 작성하고, 그것을 통과시키는 방향으로 구현한다.
4. §12.3 통합 수용 기준으로 완료를 판정한다.

## 픽스처 주의

`fixtures/*.html`은 **본문 컨테이너의 innerHTML**이다(전체 페이지가 아니다).
`raw.json`에 저장되는 것과 같은 형태이므로 convert 이후 단계 테스트에 그대로 쓸 수 있다.

probe 단계 테스트(T-P2~T-P6)에는 전체 페이지 HTML이 필요하다.
`crawl2md probe --save-fixtures fixtures/`로 직접 만든다. 명세 §12.1 참고.

## 명세에 정의되지 않은 것

임의로 채우지 말고 보고한다. 그것은 명세의 결함이다.
